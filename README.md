# KartTube Online · descargas

Descargas públicas del **KartTube Launcher** (Windows y Linux) y de los **parches de KartTube**, que el launcher instala solo.

- **Launcher:** en [Releases](https://github.com/kartubestudio/karttube-releases/releases). Una vez instalado, se actualiza solo.
- **Parches** (`parches/`): catálogo firmado. El launcher solo acepta parches con la firma de KartTube y comprueba cada archivo antes de usarlo.

Este repositorio no contiene el juego ni archivos de Nintendo: cada jugador usa su propia copia de Mario Kart Wii PAL.
Proyecto de fans sin ánimo de lucro, no afiliado a Nintendo. Web: https://karttube-project.pages.dev
